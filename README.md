# SpotRent Backend

### Features:
- Authentication: email, Google OAuth
- Authorization: role-based, JWT
- Viewing, filtering and searching workspaces
- Booking premises
- Subscription management with support of workspace owner created subscription plans
- Workspace owners can create and edit premises and subscription plans, and view and modify booking and subscription records
- System administrators can create owner and administrator accounts, and delete subscription plans
- Logging

### Stack:
- .NET 8
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
